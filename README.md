# NIMEX Pickup Vehicle Dashboard

หน้าเว็บรายงานรถเข้ารับสินค้า (BKK 3 DC: 610, 621, 691) อ่านข้อมูลจาก Google Sheet ผ่าน Apps Script

- ไม่มีตัวเลขใน repo นี้ ข้อมูลทั้งหมดอยู่ใน Google Sheet ห้ามนำไฟล์รายงาน NIMEX016267 หรือไฟล์ HTML ที่ฝังข้อมูลขึ้น repo
- repo นี้เป็นสาธารณะ ใครก็เห็นโค้ดได้ และถ้าเปิดลิงก์เว็บให้ทุกคน ข้อมูลก็เปิดตามนั้น
- ผู้ชมทั่วไปเปิดลิงก์ตามปกติ ผู้ดูแลเปิดด้วย `#admin` ต่อท้ายลิงก์แล้วใส่รหัส
- รหัสผู้ดูแลเก็บใน Script Properties ชื่อ `ADMIN_KEY` ของ Apps Script เท่านั้น
- ผู้ดูแลเติมข้อมูลเดือนใหม่จากเมนู ⋯ → อัปโหลดไฟล์ใหม่ ระบบแสดงสรุปให้ตรวจก่อนบันทึก วันที่ซ้ำจะลบของเดิมแล้วยึดค่าใหม่
- การตั้งค่าในหน้าตั้งค่า (คอลัมน์ตาราง DC, ลูกค้าที่ยกเว้น, เวลาตัด) บันทึกลง Sheet ผู้ชมทุกคนเห็นค่าเดียวกัน
- ที่อยู่ระบบข้อมูลตั้งไว้ใน `config.js` เมื่อแก้หน้าเว็บให้เพิ่มเลข `PICKUP_V` เพื่อล้างแคช
- โค้ดฝั่ง Apps Script อยู่ใน `Code.gs.txt`
